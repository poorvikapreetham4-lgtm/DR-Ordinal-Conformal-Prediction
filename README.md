# DR-Ordinal-Conformal-Prediction
An AI-based Diabetic Retinopathy grading project using EfficientNet-B0 and Ordinal Conformal Prediction. Implements LAC, APS, RAPS, and Ordinal methods to estimate prediction uncertainty and generate reliable prediction sets from retinal fundus images. Evaluates coverage, average prediction set size, and continuity across DR severity grades.
